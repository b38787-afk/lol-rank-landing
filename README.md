# 명작팀 정적 사이트

GitHub Pages는 `main` 브랜치의 루트 파일을 공개합니다. 별도 패키지 설치는 필요하지 않습니다.

## 스타일 수정

메인 화면 스타일의 원본은 `css/style.css`입니다. 초기 화면이 추가 스타일 요청을 기다리지 않도록 배포용 `index.html` 안에 포함합니다. 원본을 수정한 후 다음 명령으로 반영하세요.

```text
node scripts/build-static.cjs
```

가이드 공통 스타일은 `css/content.css`, 가격 계산기 스타일은 `css/pricing.css`입니다.

## 가격 변경

홈페이지 가격표, `pricing/index.html`의 옵션·표·기본 표시, `js/price-calculator.js`의 단가를 함께 변경해야 합니다. 언랭크는 판수, 나머지 표기 구간은 승수 단위입니다. 마스터 이상은 상담 전용입니다. 1:1 강의 요금은 계산 대상이 아닙니다.

## 검색 설정

- `sitemap.xml`: 검색 대상 페이지 목록. 새 페이지의 대표 URL을 추가합니다.
- `feed.xml`: 최신 가이드 RSS. 새 가이드 발행 시 갱신합니다.
- 메인 HTML의 소유 확인 태그·Google 확인 파일은 확인 후에도 유지합니다.
- 검색로봇용 robots.txt는 이 프로젝트 폴더가 아니라 호스트 최상위에 있어야 합니다. 해당 파일은 `b38787-afk.github.io` 저장소에서 관리합니다.

## 분석 이벤트

`js/marketing-events.js`는 `gtag`가 별도로 연결된 경우에만 상담·가격·강의 이동 이벤트를 전송합니다. 이 파일 자체는 Google Analytics를 로드하지 않으며 현재 측정 ID도 설정하지 않았습니다. 분석 계정 연결과 데이터 수집 설정은 운영자 승인 후 진행해야 합니다. 버튼 클릭은 실제 상담이나 구매를 뜻하지 않습니다.

## 이번 작업 범위

사용자 요청으로 기존 서비스 구성, 상담 링크, 실적·후기와 환불 안내는 유지했습니다. 새 가이드·가격 계산기·검색 및 공유 메타데이터를 추가했습니다. 폰트 로딩 방식과 장식 배경의 접근성 정보는 기술 점검 결과에 따라 개선했습니다.
